# Tran’s portfolio

Unzip the project and open the **Tran-Portfolio** folder in VS Code. Open **index.html** to edit. Press **F5** to preview in Chrome, or double-click **index.html** in Finder to preview in your default browser. Save your edits and refresh the browser.

## Where to edit

- Search for `<!-- HOME` to find the introduction, selected work, and education.
- Search for `<!-- CASE STUDY` to edit the four individual project stories.
- The `<style>` block controls colors, typography, and mobile layouts. The `<script>` block handles the photo album, filters, navigation, and gripper model.
- Replace the files in `assets/` to swap photos and your résumé, or edit their paths in the HTML. The photo album’s captions and additional slides are in the `photos` array.
- All the code for the gripper geometry is in `index.html`. The bundled Three.js library is in `assets/three.min.js`.

## Updating an existing copy

To update the Pacman page in a folder you already edit, replace `assets/earlier-projects/pacman-ai.html` with the file from this download. If your older portfolio folder contains `assets/earlier-projects/multiAgents.py` or `Update-my-copy.html`, move those files outside the portfolio folder before sharing it.
